## 📌 Project Overview

A responsive single-page web application developed in **Lecture 11** for tracking books across reading states: **Currently Reading**, **Completed**, and **Want to Read**.

---

## ✨ Features

- **Reading Dashboard Statistics:** Live summary counts of total, reading, completed, and wishlisted books.
- **Categorical Filtering:** Quick filter tabs (`All`, `Reading`, `Completed`, `Want to Read`).
- **Real-Time Search:** Instant search by book title, author, or genre.
- **Interactive Add/Remove Flow:** Modal dialog form to add new books with custom genre and 1-5 star ratings.
- **Persistent Local Storage:** Retains user reading lists across browser sessions without requiring a database.
- **Responsive Modern UI:** Modern card design with custom status tags and star ratings.

---

## 💻 Tech Stack

- **HTML5:** Semantic components, modal overlay, form controls.
- **CSS3:** Flexbox, CSS Grid, custom properties, responsive breakpoints.
- **JavaScript (ES6):** `localStorage` API, JSON serialization, dynamic card rendering, event handling.

---

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open `index.html` in any web browser.
3. No build tools or servers required!
